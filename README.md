# vocab

A minimal vocabulary learning app in a single HTML file.

## Features

- 56,000+ words across CET-4, CET-6, 考研, IELTS, TOEFL, GRE
- Spaced repetition algorithm
- Favorite words collection (stored locally in browser)
- Custom vocabulary books with bulk import
- Text-to-speech pronunciation
- Customizable theme colors

## How to use

1. Download `index.html` and `brat-vocab-data.js`
2. Put them in the same folder
3. Open `index.html` with any browser

## Data source

Vocabulary data extracted from [kajweb/dict](https://github.com/kajweb/dict), an open-source English-Chinese dictionary project.
